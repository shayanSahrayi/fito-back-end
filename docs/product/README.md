# طراحی محصول بک‌اند Fito

وضعیت این پوشه: **پیشنهاد طراحی مرحله اول**. پیاده‌سازی شروع نشده است.

این اسناد مرجع ادامه کار هستند تا طراحی به حافظه گفتگو وابسته نماند. تا وقتی سفارشی با شناسه مرحله داده شود، مثلاً «برو مرحله F01»، هیچ migration، مدل یا API محصولی ساخته نمی‌شود.

## معنی برچسب‌ها

| برچسب | معنی |
| --- | --- |
| نیاز محصول | در تعریف فعلی محصول صریح است |
| پیشنهاد | طراحی پیش‌فرض برای اجرا؛ تصمیم قطعی تجاری نیست |
| تصمیم باز | اگر قبل از مرحله مربوط عوض شود، رفتار یا جدول تغییر می‌کند |
| پیاده‌سازی‌شده | در مخزن همین بک‌اند واقعاً وجود دارد |
| آینده | صریحاً خارج از نسخه فعلی است و شناسه مرحله ندارد |

هیچ پیشنهاد تجاری‌ای در این اسناد به‌عنوان تصمیم نهایی محصول معرفی نشده است.

## مرز این طراحی

بک‌اند Laravel و API مشترک وب، Android و iOS است. مدیریت شعب باشگاه، حضور و غیاب، تجهیزات، چت بلادرنگ، مارکت‌پلیس مربی، تسویه شهریه ورزشکار و خدمات مستقل ورزشکار بدون مربی در این طراحی جدول و مرحله ندارند.
